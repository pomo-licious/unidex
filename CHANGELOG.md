# Changelog

All notable changes to Unidex are documented in this file.

## v0.2.0 — College Profile Pages (03 Jun 2026)

### Added
- College detail page (`/college/:id`) with placement stats, courses, cutoffs, scholarships
- Placement data seeded for top 20 colleges
- College cards and tracker cards link to detail page

## v0.1.0 — MVP Scaffold (01-02 Jun 2026)

### Added
- **Auth**: signup, login, route protection, email verification
- **College Directory**: 71 colleges, match scores based on CAT percentile, Add to Tracker feature
- **Application Tracker**: Kanban board by status, SOP checklist, notes, Apply Now demo (4-step wizard)
- **Deadline Calendar**: Exam calendar with registration dates, fees, accepting colleges
- **Document Upload**: Resume, transcripts, profile photo storage
- **Notifications**: Reminder bell, notification center
- **Rejection Recovery**: Modal with encouragement and next steps
- **Offer Celebration**: Confetti animation, referral feature
- **Investor Demo Mode**: Demo account (demo@unidex.co.in with CAT 99.13%)
- **Deployment**: biz.vercel.app, custom domain unidex.co.in configured
- **Tech**: React + Tailwind + Vite, Supabase auth + database, Vercel hosting
