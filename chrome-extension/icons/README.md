# Unidex Extension Icons

Add the following icon files to this directory:

- **icon16.png** (16x16px)
- **icon48.png** (48x48px)
- **icon128.png** (128x128px)

Design specification:
- Background: Dark navy (#1a2744)
- Logo: Gold (#c9a84c) "U" lettermark
- Style: Clean, minimalist, professional

The icons should use the Unidex brand colors and be crisp/readable at all sizes.
